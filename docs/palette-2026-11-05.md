# Palette ratio — decision, and the measured state of the delivered site

**Decision (2026-11-07, lane swe):** the bands in `PALETTE-SPEC-2026-11-05.md` §3
are kept as a hard rule **on the whole delivered page** — black 70–80%, white
10–15%, accent 4–14%, pink ≤ 1%, no fifth colour — and every page is brought
inside them. Option 1 of the two this document previously listed is taken;
option 2 (scoping the ratio to the fold) is **not** used.

Tyler can override this, and the override is cheap: it is a change to the
`RATIO-TUNING` block, not to the composition.

Why option 1: §3 says the ratio is "a budget measured on the delivered file,
never on the layout intention", and every page here is one delivered surface.
Scoping to the fold would have made the short pages pass without touching them,
which is the measurement bending to the design rather than the design meeting
the rule.

## What was wrong

The live tree (`main` @ d2862d0) put the accent on text colour, dots and a thin
button fill: measured 0.03–0.55% accent on every page, 0/10 surfaces in band.
Branch `site/palette-plates` (2c2e3ca) added the accent plate + ink plate and
measured 0/10 the other way (accent 8–30%, ink 11–39%): the plates were a fixed
pixel height while the bands are a percentage of the page, so on a 1910 px page
the same 594 px plate is 31% and on the 7170 px home page it is 8.5%.

## What changed

1. **Closing bands are the ratio control, solved per page and per layout
   region.** `scripts/ratio_solve.py` renders every page at 1440, 1024, 820 and
   390, classifies the pixels with the brand pack's own `audit_palette.py`, and
   solves the two band heights that put the surface inside the bands; it writes
   the result into the `RATIO-TUNING` block at the foot of `assets/style.css`.
   That block is padding on the accent band (`.contact-in`) and on the ink plate
   (`footer.site-foot.plate`), keyed to the stylesheet's own breakpoints
   (1100 / 1020 / 760). Nothing in it is guessed and nothing in it is a colour.
2. **Short pages carry the compact closing band** — headline + one action, no
   band label, no body paragraph — as agreed. The long home page keeps the full
   band (label, paragraph, action), because on a 7 200 px page there is room and
   the ratio wants the accent mass.
3. **The site/follow link index moved from the ink plate to a field (black)
   section** that closes the content: `section.page-index`. The ink plate keeps
   the two contact links and the legal line. Without that move the ink plate
   carried ~590 px of links on a 1 300 px page, and no padding value can bring
   28% white under a 15% ceiling. The links are not lost — they are one section
   earlier, on the field, which is also 250–500 px more black per page, which is
   the direction the ratio wants.

## Measured result

Full receipt in `docs/palette-audit-2026-11-05.txt` (the checker's own output,
20 surfaces, all PASS). The delivered numbers, from that run:

| page | 1440 black/white/accent | 390 black/white/accent |
|---|---|---|
| home | 79.50 / 11.99 / 8.51 | 79.50 / 11.99 / 8.51 |
| learn | 79.49 / 11.95 / 8.56 | 79.50 / 11.97 / 8.53 |
| merch | 79.07 / 12.55 / 8.38 | 79.50 / 12.92 / 7.59 |
| giveaways | 79.52 / 11.99 / 8.49 | 79.51 / 12.00 / 8.49 |
| affiliates | 75.64 / 14.46 / 9.91 | 78.45 / 14.50 / 7.05 |

The two intermediate regions the stylesheet has breakpoints for (1024, 820) are
in the same run and pass as well — 20/20. Pink is ≤ 0.001% (one index numeral on
the home page's card grid, P-05); `other` is 0.000% everywhere, so there is no
fifth colour in any delivered pixel.

Affiliates at 1440 is the thinnest page in the set (1 316 px) and lands at 75.6 /
14.5 / 9.9: it is inside the bands, with less room than the others because its
content is genuinely short.

## Reproduce

```
cd ~/.hermes/shared/dotbang-brand-2026-11-05
python3 tools/render.py <cfg: the five pages x [1440,1024,820,390]>   # renders
python3 tools/audit_palette.py --check <out>/*-full.png              # the verdict
```

or, to re-solve the block instead of checking it:

```
DOTBANG_BRAND=~/.hermes/shared/dotbang-brand-2026-11-05 \
  python3 scripts/ratio_solve.py --apply    # writes assets/style.css
```

Re-run the checker after any change to the closing bands, to the page copy, or
to the footer: the ratio is a percentage of the page, so a page that grows or
shrinks moves the ratio with it.
