dotBANG site — palette audit receipt
=====================================

Surface: every delivered page of the site in this commit (index + 4 subpages),
at the four layout regions the stylesheet defines (1440x900, 1024x768, 820x1180,
390x844). Full-page renders, real Chromium. Nothing here is a layout intention:
each number is the classification of the delivered pixels.

Checker:  dotBANG brand pack, tools/audit_palette.py (BAND constants, §3 of
          PALETTE-SPEC-2026-11-05.md)
Render:   dotBANG brand pack, tools/render.py (same config the audit was run on)
Solver:   scripts/ratio_solve.py in this repo writes the RATIO-TUNING block in
          assets/style.css; these are the numbers it lands on.

Reproduce from the brand pack directory:
  python3 tools/render.py cfg.json          # pages x [1440,1024,820,390]
  python3 tools/audit_palette.py --check <out>/*-full.png

Bands: black 70-80, white 10-15, accent 4-14, pink 0-1, no fifth colour.
